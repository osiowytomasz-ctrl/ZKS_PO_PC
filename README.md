# ZKS PO – strona aplikacji na iPhone'a

To repozytorium służy już tylko do hostowania strony aplikacji **ZKS PO na iPhone'a** (GitHub Pages, gałąź `gh-pages`):
https://osiowytomasz-ctrl.github.io/ZKS_PO_PC/

Kod programu PC, aplikacji na Androida i wersji na iPhone'a jest w prywatnym repozytorium **ZKS_PO**.
Gałąź `gh-pages` jest wgrywana automatycznie przez workflow z tamtego repozytorium – nie edytuje się jej ręcznie.
